# Revio 0.1.0

The first public release.

Revio is a macOS app for running AI coding agents side by side. Each task gets its own workspace:
a separate branch and checkout of your repository, with its own agent chats, terminal and diff
view. A workspace runs on your Mac as a git worktree, or in the cloud in its own sandbox on your
Vercel account.

## Install

You need a Mac with Apple silicon and macOS 13.4 or later.

1. Download `Revio-0.1.0-arm64.dmg` below, open it, and drag **Revio** to **Applications**.
2. Open Revio. macOS blocks the first launch, because the app is not notarized by Apple yet.
   Approve it once:
   - **macOS 15 or later:** click **Done**. Open **System Settings › Privacy & Security**, scroll
     down to **Security**, and click **Open Anyway**. Click **Open Anyway** again, then confirm
     with Touch ID or your password.
   - **macOS 13 or 14:** in **Applications**, Control-click **Revio**, choose **Open**, then click
     **Open**.
3. Install Git and at least one coding agent CLI, for example
   [Claude Code](https://docs.anthropic.com/en/docs/claude-code). The GitHub CLI (`gh`) comes with
   the app.

The [README](https://github.com/karimmila/Revio#quick-start) shows how to create your first
workspace, how to set up cloud workspaces, and how to bring your work from another app.

## What is in this release

- Workspaces on your Mac (git worktrees) and in the cloud (one Vercel Sandbox per workspace)
- Chat with Claude Code and Codex, and with OpenCode, Grok, Antigravity and OMP through the Agent
  Client Protocol
- A setup script for each repository, and actions that you and your agent can run
- A diff view with comments for the agent, and check status with one-click fixes
- **Create PR** with Revio's own GitHub sign-in, on your Mac and in the cloud. You do not need
  `gh auth login`.
- A desktop for each cloud workspace, public links for sandbox ports, and sleep and wake
- Archive and restore, with chats and uncommitted work
- Import of your workspaces, chats and scripts from another app on first launch
- Credentials that stay on your Mac: a cloud sandbox holds placeholders only
- Trust prompts: Revio asks before a repository's agent hooks, MCP servers, setup script or
  shared actions run on your Mac
- A notice when a new version is available, **Check for Updates…**, **Report an Issue…** and
  **Open Logs Folder** in the menus
- New workspaces in `~/revio/workspaces`, and no account, analytics or crash reports

## Known limits

- **Apple silicon only.** There is no build for Intel Macs, Windows or Linux.
- **First-launch approval.** The app is not notarized, so you must approve it once in System
  Settings (see Install).
- **Updates are manual.** Revio shows a notice when a new version is available, but it does not
  install it. Download the new release and replace the app in **Applications**. Your workspaces,
  chats and settings stay.
- **Computer use is not included.** Agents cannot control apps on your Mac in this release.
- **Cloud workspaces need your own Vercel account and a repository on GitHub.** Vercel bills that
  account for the sandboxes. In the cloud, Revio supplies a credential for Claude Code only.
- **No status for agents that you start in the terminal.** Chats show working and waiting states.
  An agent CLI that you run in the terminal panel does not.
